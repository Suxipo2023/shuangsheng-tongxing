# 双生同行・双人合作解谜游戏

> 两个人，一段路，从此不可独行。

一款零单人可能性的纯合作向双人解谜游戏。黑白两个小人各有一套操作键位，玩家需要默契配合，跨越 15 个精心设计的关卡，抵达终点 —— 而同行到最后的人，还会发现一段隐藏的彩蛋旅程。

## 🎮 操作说明

**黑色小人**：`W` 跳跃，`A` 左移，`D` 右移
**白色小人**：`↑` 跳跃，`←` 左移，`→` 右移
**通用**：`R` 重置当前关卡；右上角 🔊 按钮开关音效；关卡选择界面可自由选择已解锁关卡

**核心玩法**

- **双人合作**：两人必须同时抵达各自对应的终点门才算通关，缺一不可
- **同生共死**：任何一人坠落或触碰尖刺，两人都需重新开始本关
- **默契考验**：踩机关、垫脚、接力，一个人是走不通的

## ✨ 功能清单

- **15 个正式关卡**：从「初遇」到「同归」，难度循序渐进，涵盖平台跳跃、机关联动、尖刺陷阱
- **第 16 关彩蛋**：通关全部 15 关后解锁，星空旅程 + 制作人员名单
- **清新渐变背景**：每关独特色调渐变
- **星空穹顶**：彩蛋关专属璀璨星空
- **移动尖刺**：动态陷阱，需精准时机配合
- **火箭烟花**：通关庆祝特效
- **音效系统**：背景 BGM + 各类音效，一键静音
- **本地存档**：自动保存通关进度
- **关卡选择**：自由跳转已解锁关卡
- **离线下载**：主菜单内置「下载离线版」按钮
