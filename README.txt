《双生同行》— 双人合作解谜游戏
==========================

【游戏简介】
《双生同行》是一款双人本地合作解谜游戏。一黑一白两个小人，
需要互相配合、彼此扶持，通过15个精心设计的关卡，
走向最后的重逢。

【操作方式】
- 黑色小人：W/A/S/D 或 方向键 ↑←↓→ 移动跳跃
- 白色小人：T/F/G/H 移动跳跃
- Tab 键：切换当前控制的角色
- R 键：重新开始当前关卡
- Esc 键：返回主菜单 / 退出关卡

【游戏玩法】
两个小人共享同一条命。只要有一个人碰到尖刺或掉出画面，
两人都要重来。善用按钮、压力板、箱子、移动平台等机关，
一起到达终点吧！

【彩蛋】
通关全部 15 关后，会解锁第 16 个神秘彩蛋关卡。
星空下，烟火为你们而绽放。

【运行方式】
双击 "双生同行 - 双人合作解谜.html"，用任意现代浏览器打开即可。
无需联网，无需安装。

【配置要求】
- 任意现代浏览器（Chrome / Edge / Firefox / Safari）
- 建议分辨率：1280×720 以上
- 键盘（双人需两个玩家共用一个键盘）
